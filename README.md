# Welcome to the Lunar Lions Team Repo for the NASA SUITS Challenge (2026)! 
This repo is for developing our EVA Astronaut assistance program on the Magic Leap 2

Welcome to the Lunar Lions team repository for the NASA Spacesuit User Interface Technologies for Students (SUITS) Design Challenge!

This repository contains our Unity project for developing an EVA astronaut assistance interface on the Magic Leap 2. Our goal is to build an augmented reality system that supports astronauts during Extravehicular Activity (EVA) through intuitive UI tools, navigation support, voice interaction, and mission assistance features.

## Project Overview

The Lunar Lions are part of the Columbia Space Initiative’s SUITS Team. For the NASA SUITS Challenge, we are designing and developing an augmented reality interface that helps astronauts access information, navigate tasks, and interact with mission tools during simulated spacewalks.

This project was completed in May 2026 and presented to NASA officials at the Johnson Space Center.

### Contribution Guidelines
To navigate the stars with us, here are the rules for contributing to the NASA SUITS repository:

#### 1. Branching Strategy
- Ensure that each subteam has their own branch for your cosmic contributions. Ideally, each subteam will also have 1 or more feature branches that will submit PR to your subteam branch.
  Example: `main <-- LTV (subteam branch) <-- CV-scripts (feature branch)` 

- If you're feeling lost in the cosmic sea, signal our wise leaders - Hiba or Grace, to receive your territory in the codebase!

#### 2. Unity Etiquette 
- Each subteam branch should have their own README.md files that gives a brief overview of the code's features, how to setup, AND the libraries (with their versions) you imported.
- ALWAYS close Unity before committing and pushing to your branch. Let's avoid space-time paradoxes and keep our coding universe in order.
- Add any unnecessary generated files (like build, log, memory captures, or mac DS files) to .gitignore. This will make merging a lot easier! Remember to leave scene, config & obj files so people can properly run your code!
- Make sure to be on `Unity Editor Version 2022.3.7` or higher. 

#### 3. Merging to Main
- Merges to the main branch will be celebrated during our out-of-this-world group meetings. Keep your creations on your own branch until the cosmic council approves a merge.
